# 🛍️ VyapaarScore

### AI-Powered Micro-Business Credit Evaluation & Underwriting Platform

VyapaarScore is an AI-powered alternative credit scoring platform designed for **micro-merchants, Kirana store owners, and MSMEs in India** who may not have sufficient traditional credit history.

The platform analyzes **UPI payment receipts, bank SMS notifications, and financial documents** using OCR and transaction analysis. Based on the extracted financial data, it generates a **VyapaarScore ranging from 300 to 900**, assigns a risk tier, and estimates an indicative micro-credit limit.

---

## 🎯 Problem Statement

Many small merchants have limited access to formal credit because they may not have:

- A strong traditional credit score
- Detailed financial records
- Sufficient credit history
- Formal business documentation

However, they regularly generate digital financial data through:

- UPI payments
- Bank transactions
- Payment receipts
- Bank SMS notifications

VyapaarScore uses this alternative financial data to create a structured credit profile for these merchants.

## ✨ Key Features

### 🔐 Secure Authentication

- Role-Based Access Control
- Merchant, Lender, and Admin roles
- Email OTP-based two-factor authentication
- Password hashing using bcryptjs
- JWT-based authentication
- Password reset functionality
- API rate limiting

### 📸 OCR-Based Transaction Extraction

The platform processes financial documents and extracts important transaction information.

Supported inputs include:

- UPI payment screenshots
- Bank SMS notifications
- Bank statement PDFs
- Manual transaction data

The system uses:

- **PaddleOCR** as the primary OCR engine
- **Tesseract.js** as a fallback OCR engine
- **pdf-parse** for PDF document processing

The extracted information includes:

- Transaction amount
- Date
- Counterparty
- Credit/Debit type
- Transaction category
- Source document

---

## 📊 VyapaarScore

VyapaarScore ranges from **300 to 900**.

The score is calculated using multiple financial indicators:

```text
VyapaarScore
=
300
+ Inflow Points
+ Net Cashflow Points
+ Transaction Frequency Points
+ Expense Management Points
```

### Scoring Components

| Component | Maximum Points | Description |
|---|---:|---|
| Base Score | 300 | Starting score |
| Inflow Volume | 250 | Based on monthly digital inflow |
| Net Cashflow | 150 | Based on income and expenses |
| Transaction Frequency | 100 | Based on transaction activity |
| Expense Management | 100 | Based on income-to-expense relationship |
| **Maximum Score** | **900** | Final score |

## 🏦 Risk Classification

| Score | Risk Tier | Description | Indicative Credit Limit |
|---:|---|---|---:|
| 750–900 | Tier A | Low Risk | Up to ₹5,00,000 |
| 680–749 | Tier B | Moderate Risk | Up to ₹2,50,000 |
| 600–679 | Tier C | Fair Stability | Up to ₹1,00,000 |
| 300–599 | Tier D | Building History | Around ₹25,000 |

> **Note:** Credit limits are indicative estimates generated by the project's scoring model and do not represent guaranteed loan approval.

## 👥 User Roles

### 👤 Merchant

Merchants can:

- Create an account
- Verify their email using OTP
- Upload financial documents
- Extract transaction data
- View transaction history
- View their VyapaarScore
- Track score history
- Download their credit report
- Control whether their report is shared with lenders
- Apply for loans

### 🏦 Lender

Lenders can:

- View merchant profiles shared with them
- Analyze merchant credit scores
- Review financial information
- Download credit reports
- Review loan applications
- Approve or reject applications

### 👑 Admin

Administrators can:

- View all users
- Manage user roles
- Monitor merchants and lenders
- View system statistics
- Monitor platform activity

## 📄 Credit Report

VyapaarScore generates a PDF credit evaluation report containing:

- Merchant information
- VyapaarScore
- Risk tier
- Total inflow
- Total outflow
- Net cashflow
- Transaction summary
- Estimated credit limit
- Digital verification information

PDF reports are generated using **PDFKit**.

## 🔒 Data Privacy

Merchant financial information is shared with lenders only when the merchant explicitly enables the sharing option.

```text
Merchant
   ↓
Credit Report Generated
   ↓
Share with Lenders?
   ↓
   ├── No → Report remains private
   │
   └── Yes → Eligible lenders can view the report
```
